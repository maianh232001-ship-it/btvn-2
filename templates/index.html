📖 Hướng dẫn

1. Định dạng file đầu vào (.xlsx)

Tool đọc file Ahrefs backlinks export (subdomains mode). Sheet đầu tiên phải có dòng tiêu đề với tên cột chính xác như sau (case-sensitive, dấu cách giữ nguyên):

Cột (bắt buộc)KiểuMô tảVí dụ
Target URLURLTrang đích của backlink — tool lọc theo từ khoá trên cột nàyhttps://www.thegioididong.com/dtdd/oppo-reno15
AnchortextAnchor text của linkoppo reno15
Referring page URLURLTrang nguồn chứa link trỏ vềhttps://vnreview.vn/oppo-reno15-review
Domain ratingsố (0–100)Domain Rating Ahrefs của domain nguồn62
First seendateNgày Ahrefs lần đầu thấy link2026-03-12

Cột tuỳ chọn (dùng để lọc Black Hat — nếu thiếu thì bỏ qua bước này):

  • Is spam — true/false; nếu true sẽ bị loại.
  • Referring page title — tool quét tiêu đề trang nguồn tìm dấu hiệu spam (casino, viagra, telegram link…).

3. Cách lấy file từ Ahrefs

  1. Vào Site Explorer, nhập domain cần audit (ví dụ thegioididong.com).
  2. Sidebar trái → Backlink profile → Backlinks.
  3. Mode chọn *.domain/* (subdomains) để lấy cả subdomain.
  4. Bấm Export → Excel (.xlsx), đợi Ahrefs gửi mail/notification khi file sẵn sàng.
  5. Tải về → upload lên tab 📁 Upload file XLSX ở trên. Hoặc bấm ⇩ Tải file mẫu trong section Demo để xem file mẫu thật.

💡 Không có Ahrefs subscription? Dùng tab 🔗 Lấy từ Ahrefs API nếu có API key, hoặc dùng file mẫu Reno15 ở section Demo để thử ngay.

4. Định dạng file đầu ra

  • Sheet 1 — Chi Tiết URL vs Anchor: liệt kê từng backlink theo Target URL, đã loại bỏ Black Hat. Dòng có DR ≥ 50 tô xanh lá.
  • Sheet 2 — 📊 Domain vs URL: đếm số link & DR cao nhất theo domain nguồn. DR ≥ 50 tô , DR 20–49 tô vàng.
