User: Có Ahrefs API key + Người dùng tự dán mỗi lần

[Tra cứu Ahrefs API v3 spec qua WebFetch + WebSearch:]
- Endpoint: GET https://api.ahrefs.com/v3/site-explorer/all-backlinks
- Auth: Bearer token
- Params: target, mode (subdomains/domain/exact/prefix), select, limit, history
- Response fields: url_from, url_to, anchor, title, domain_rating_source,
  first_seen_link, is_dofollow, is_spam

[Thực hiện code:]

1. audit.py — thêm:
   - AhrefsAPIError class
   - fetch_from_ahrefs(domain, api_key, mode, limit, history, timeout):
     • Strip scheme, set headers, urlencode params
     • urllib.request.urlopen với try/except cho 401/403/429
     • Map response fields → XLSX-style dict keys
   - _build_report (refactor) — pipeline chung cho cả 2 mode
   - run_audit_from_ahrefs(domain, api_key, keyword, output_path, ...)

2. app.py — thêm route:
   - POST /api/audit-ahrefs nhận JSON {domain, api_key, keyword,
     product_label, mode, limit}
   - Validate (max limit 10000), gọi run_audit_from_ahrefs
   - Catch AhrefsAPIError → trả message tiếng Việt

3. UI:
   - templates/index.html: 2 tab "📁 Upload file XLSX" / "🔗 Lấy từ Ahrefs API"
   - Form Ahrefs: domain + API key (password) + keyword + label + mode +
     limit (1-10000) + warning credit
   - Link tới app.ahrefs.com/api để lấy key
   - style.css: thêm .tabs, .tab-panel, password/number/select inputs
